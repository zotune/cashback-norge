# Cashback Varsler

Viser cashback-tilbud automatisk når du handler på nett i Norge.

## iPhone / iPad

1. Installer **[Userscripts](https://apps.apple.com/no/app/userscripts/id1463298887)** fra App Store (gratis)
2. Aktiver i **Innstillinger → Safari → Utvidelser → Userscripts** → velg **Tillat alltid**
3. **[Klikk her for å installere scriptet](https://zotune.github.io/cashback-norge/cashback-varsler.user.js)**

Scriptet oppdaterer seg selv automatisk.

## Chrome / Firefox (desktop)

Last ned og installer extensionen manuelt fra `dist/extension/` etter bygging.
